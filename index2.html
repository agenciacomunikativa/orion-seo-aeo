Como configurar: No WordPress, instale o plugin Application Passwords (nativo desde WP 5.6). Acesse Usuários → Perfil → Application Passwords, crie uma senha e copie aqui. A URL da API é https://seudominio.com.br/wp-json/wp/v2
O ORION se comunica com o WordPress via REST API nativa. Não é necessário nenhum plugin adicional além do Application Passwords. Todas as operações (criar/editar páginas, upload de mídia, atualizar produtos) são feitas via HTTPS.
